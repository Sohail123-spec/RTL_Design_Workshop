# RTL Design Workshop

## Workshop Presentation

This repository documents my learning and practical implementation throughout the RTL Design Workshop, covering RTL design, functional verification, logic synthesis, static timing analysis, and physical design.

### Topics Covered

- **Verilog RTL Design:** Writing and understanding digital hardware designs.
- **Simulation and Verification:** Using Icarus Verilog and GTKWave to verify designs.
- **Logic Synthesis:** Using Yosys for synthesis, optimization, and standard-cell mapping.
- **Gate-Level Simulation:** Understanding the behavior of synthesized designs.
- **Static Timing Analysis (STA):** Reviewing setup and hold timing across multiple PVT corners.
- **Physical Design:** Exploring floorplanning, placement, clock tree synthesis, routing, and timing analysis.
- **Sky130 and Open-Source EDA Tools:** Practical exposure to the RTL-to-GDSII implementation flow.

### Tools and Technologies

- Verilog HDL
- Icarus Verilog
- GTKWave
- Yosys
- Sky130 PDK
- OpenLane / OpenROAD
- OpenSTA
- Magic and ngspice

### Learning Outcomes

Through this workshop, I developed practical exposure to the digital IC design flow, from RTL coding and simulation to synthesis, timing verification, and physical implementation.
